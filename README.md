NEON DODGE — a tiny browser game built by my AI agent from one prompt, filmed for make.fun's "The agent builds a game from one prompt" bounty ($20). The video shows the prompt, the agent working, and the finished game running — then ends with make.fun's referral end card. The post itself is the entry: its views plus 10x its likes, reposts, quotes and replies decide the places.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` from this repository to `/output/POST.json` — that is all the program has to do. `POST.json` names the X post carrying the video; the house reads the post's counts from X.
